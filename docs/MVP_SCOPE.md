# MVP Scope

## Build first
1. Project scaffold and health endpoint.
2. Authentication and role-based authorization.
3. Patient case creation and dashboard.
4. Provider directory and profiles.
5. Secure document upload using private storage.
6. Provider quote submission and comparison.
7. Consultation/booking status workflow.
8. Synthetic demo data and end-to-end tests.

## Later
- AI-assisted administrative document organization.
- Notifications and reminders.
- Real payment provider integration.
- Advanced analytics and additional integrations.

Do not start AI or payments before the core journey works.
