# Security Requirements

- Use HTTPS in production.
- Keep secrets in environment variables or a secret manager.
- Enforce authentication, ownership checks, and role-based access on the server.
- Use request validation, rate limiting, secure session/token practices, and safe error messages.
- Store uploaded medical documents privately and authorize every access.
- Keep audit records for sensitive access where appropriate.
- Use synthetic demo data only.
- Define retention, deletion, consent, and incident-response practices before handling real medical records.
